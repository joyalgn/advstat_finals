# ADVSTAT

Simple Linear Regression + Hypothesis Testing (z-test / t-test).
Built with HTML, CSS and TypeScript (compiled to JavaScript). No frameworks.

## Run locally
1. `npm install`
2. `npm run dev`   (keeps compiling TypeScript into public/js)
3. Right-click `public/index.html` and choose "Open with Live Server"

## Deploy
Push to GitHub, then import the repo in Vercel (Framework Preset: Other).
Build command: `npm run build` | Output directory: `public`
